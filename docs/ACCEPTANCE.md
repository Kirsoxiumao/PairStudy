# 两台手机最终验收

以下步骤用于真实手机环境，不代表已在本机自动完成的测试；自动化结果单独记录于 VERIFICATION.md。

1. 在电脑启动后端与 MySQL；两台手机浏览器均能访问 `/api/health`。
2. 安装 APK，登录页设置相同服务器地址。两台手机分别注册不同账号。
3. A 生成邀请码，B 输入绑定；A 点击“朋友已绑定，刷新进入”。
4. A 创建分区；B 刷新分区页，确认名称和顺序一致。
5. A 发布文字和 1/4/9 张图片各一条；B 刷新首页，确认顺序、文字、时间和图片预览。
6. B 发布一条；两台手机首页均显示双方已打卡，日历当天圆的两边都填充。
7. 点日期分别看到自己和搭子的记录；分区详情的三种筛选正确。
8. 多于 20 条记录时点击加载更多，确认全部可达。
9. 分区改名、上下移和归档后，双方刷新一致；归档历史仍可查看。
10. 删除自己的记录后重算日历；无按钮可删除搭子的记录。
11. 在北京时间 03:59 发布记录属于前一天；04:00 发布属于当天。自动化已用受控后端 Clock 测试，无需修改生产机器日期。
12. 关闭网络尝试刷新，出现友好错误；恢复网络可重试。
13. 关闭再打开 App，JWT 有效时回到当前空间；退出登录后回到登录页。
14. 手机回到前台会刷新状态，跨 04:00 后服务器返回新学习日。
15. 用另外两个测试账号组成不同空间，确认双方数据独立，不能通过改记录 ID 或图片 URL 越权。

布局检查：大字体/小屏幕、华为系统 Photo Picker 回退、带刘海导航栏、安全区域、长昵称/长分区名/9 张图片。纯 HarmonyOS NEXT 不属于 APK 安装验收范围。
